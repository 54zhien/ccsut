# Campus UI Refactor Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 重构校园三个服务内部 UI，保持现有 App 风格并交付可验证的新包。
**Architecture:** Foundation 展示格式独立；共享 SwiftUI 分组/摘要组件供记录、表单、电费视图使用。保留现有模型、状态与网络生命周期，仅增加 DEBUG 合成预览。
**Tech Stack:** SwiftUI/UIKit iOS26，Foundation runners，XCTest UI，macOS CI。
**Spec:** `docs/superpowers/specs/2026-10-24-campus-ui-design.md`，按用户此前直接实施要求执行。

## Global Constraints

- 不改导航/其他模块、API、提交逻辑或付款模型；三个电费业务文件与当前 `cab3b74` 一致。
- 不读取敏感抓包制作 fixture，不发真实申请/支付/上传；号码继续脱敏。
- 玻璃只用于操作/导航，内容用语义实色背景；现有蓝色、系统字体、28pt 圆角。
- 保留全部可见业务字段和原有按钮动作、账号隔离、未知结果查询。

## Review Focus

- 记录日期缺失/异常/跨年、超长文本、未知状态不制造业务含义或暴露数字。
- 打开/关闭表单与切换离返校，旧数据、当前选择和刷新生命周期保持。
- 键盘、最大字号、横屏与小屏下输入区、日期和主操作保持可达。
- 电费金额绑定、快捷金额、确认和免密说明不变；DEBUG 预览不触发网络/支付。
- 深色、iPad 与减少动态效果下信息层级、对比度及触达有效。
