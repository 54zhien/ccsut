# 请假条皮质票夹设计

日期：2026-10-26
分支：codex/leave-ticket-wallet
基线：origin/main @ fe11d41
状态：待确认视觉细节后实施

## 已确认的需求

请假页改为请假条票夹页。所有请假条初始叠放在同一个皮质票夹包里；点击翻开包盖，请假条从上到下展开铺列。新增成功时使用所提供的出票动效。页面背景允许改色并营造氛围。本次在独立分支开发。

## 方案与取舍

已讨论完整展开的票据列表和叠放票夹两种形式，用户选择叠放票夹，并指定皮质包体。保留现有 SwiftUI 页面和学校申请流程，在出票动画局部嵌入 UIKit，避免把整个校园页面重写成 UIKit。参考 Swift 的常量与裁剪思路可用，但先纠正此前发现的宽度、遮挡和生命周期矛盾，不将其自称的 1:1 当成已验证事实。

## 建议的视觉细节

浅色模式使用暖灰米色背景与低对比柔和渐变，深焦糖棕皮质票夹，细密压线、包边、克制的皮革纹理与接触阴影；票纸为暖白色。深色模式使用偏棕炭灰背景、深棕皮革和适当降低亮度的票纸。氛围不依赖持续运动，日期与状态保持清晰对比。以上配色为开发建议，尚未由用户逐项确认。

关闭状态：包盖合上，露出少量错层票边；仅使用真实记录数量，不为分页未加载的内容编造张数。空状态仍展示票夹和添加入口。
打开状态：包盖翻开，票据依序向下展开为可滚动列表；顶部保留票夹与收起入口。每张票显示请假类型、起止时间、天数、事由、申请时间和真实审批状态。长事由、多行日期、大字体不得裁切重要信息。
收起状态：票据回收、包盖合拢；动画可取消，快速切换不会留下透明占位或重复票据。

## 添加与出票

保留现有原生表单、核对和学校提交。仅确认提交成功后，用户完成表单并返回票夹时触发一次出票；取消、提交失败、普通刷新和重新进页不触发。

出票使用局部裁剪窗口、票纸旋转 90 度与 0.9 缩放，以及 0.52 / 0.06 / 0.08 的 spring 参数。出票后新票进入票夹；如票夹原本展开，落入列表顶部并保持展开，如原本关闭，则收入包内并保持关闭。落位过程的缩放和旋转保证从窄票到完整可读票面连续过渡。

动画不得代替数据确认：提交成功后刷新学校记录，无法确认新记录时显示已提交/正在同步，不从表单虚构带审批状态的正式票据。超时或刷新失败不重新提交申请。具体匹配依据需在实施前核实提交接口返回值与记录 ID。

## 技术边界

仅调整请假页呈现与提交成功后的 UI 衔接；节假日离返校、登录、缴费及申请业务规则保持既有逻辑。列表保留分页、下拉刷新、错误重试和已加载数据。

出票与收纳采用单次事件和可取消的阶段状态；离页、账号更换、重复点击会失效旧回调并停止触感。连续触感在出票结束/取消时停止，随后播放完成反馈。减弱动态效果时直接切换布局并跳过出票与翻盖位移。VoiceOver 可打开/收起票夹、添加和逐张读取展开票据；收起的票纸不进入可访问性树。

## 验证范围

验证关闭、展开、收起、空票夹、多票、长文本、深浅色、大字体、减弱动态效果、分页和刷新。验证成功添加仅播放一次、取消/失败不播放、离页和账号切换不会串场。使用预览与测试数据检查动效，不发送真实请假申请。
