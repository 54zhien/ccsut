# 历史接口调试脚本

这里保留开发早期用来查看学校登录、课表、成绩、选课和校园接口的脚本。它们不参与 iOS App 构建，也不会打进 IPA；接口变动后，部分脚本可能已经不能使用。

常见文件：

- `_cas*.mjs`：登录页面与认证流程。
- `_kb*.mjs`、`_dj.mjs`：课表数据。
- `_cj.mjs`、`_ss.mjs`：成绩页面。
- `_deep*.mjs`、`_detail.mjs`：选课数据与课程详情。
- `_har*.mjs`：分析本地抓包记录。
- `_e2e.mjs`、`_e2e2.mjs`、`_probe2.mjs`：包含真实选退课操作，默认拒绝运行。

需要人工调试时，从**仓库根目录**执行 `node tools/experiments/<文件名>.mjs`。脚本仍从根目录下的 `out/` 读取本地会话或抓包数据；不要切换到本目录运行，也不要上传这些数据。

不要批量执行这些脚本。写入脚本要求显式传入 `--allow-school-writes`，运行后可能改变真实选课结果。自动测试只检查它们的默认拒绝行为，不执行学校写入操作。

日常采集和会话工具在上一级 `tools/`，入口仍是根目录的 `npm run capture`、`npm run keepalive`。
